​🛡️ Projeto Sentinela Mulher v1.3.0
​O Sentinela Mulher é um sistema de inteligência e proteção ativa desenvolvido para garantir a eficácia das Medidas Protetivas de Urgência (Lei Maria da Penha). Através de algoritmos de geofencing (cercas virtuais), o sistema monitora a distância entre agressor e vítima, notificando autoridades e a pessoa protegida antes que ocorra o contato físico.
​📋 Funcionalidades Principais
​Monitoramento em Tempo Real: Cálculo geodésico de precisão entre coordenadas de agressores e vítimas.
​Registro Pericial (Pilar 3): Armazenamento imutável de logs de invasão (data, hora, local e distância) para uso como prova judicial.
​Alertas Automáticos (Pilar 1): Protocolo de notificação via mensageria para a vítima ao detectar violação do perímetro.
​Consciência Situacional: Integração imediata com Google Maps para visualização tática e despacho de viaturas.
​Segurança Institucional: Acesso restrito via protocolos OAuth2 (Token Bearer).
​🚀 Tecnologias Utilizadas
​Linguagem: Python 3.10+
​Framework: FastAPI
​Banco de Dados: SQLAlchemy (SQLite/PostgreSQL)
​Geolocalização: Geopy (Algoritmo Geodésico)
​Servidor: Uvicorn / Render
